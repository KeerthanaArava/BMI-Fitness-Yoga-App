# BMI Fitness Yoga App

A web-based BMI Calculator and Wellness application built using Python Flask, HTML, and CSS.

## Features

- BMI calculation using weight and height
- BMI category classification
- Personalized workout guidance
- Personalized yoga guidance
- Personalized nutrition guidance
- Responsive user interface

## Technologies Used

- Python
- Flask
- HTML
- CSS

## BMI Categories

| BMI | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal |
| 25 – 29.9 | Overweight |
| 30 – 34.9 | Obesity |
| 35 and above | Severe Obesity |
